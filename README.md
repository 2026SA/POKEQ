# POKEQ（ポケキュー！）

9匹のポケモンを1〜9に対応させて遊ぶ、数独Webアプリです。GitHub Pagesでそのまま公開できます。

## 数字とポケモン

1. ピカチュウ
2. イーブイ
3. ポッチャマ
4. ヒトカゲ
5. ゲンガー
6. ホゲータ
7. ニャオハ
8. クワッス
9. ミュウツー

## 主な機能

- 9×9数独／3×3ブロック
- かんたん・ふつう・むずかしい
- ポケモン画像をタップして入力
- 数字表示ON/OFF
- 行・列・3×3ブロックの重複チェック
- 答え合わせ
- やりなおし／新しい問題
- タイマー
- スマホ・タブレット対応
- クリア時に9匹を3×3で表示する全員集合画面

## GitHub Pagesで公開

1. GitHubで `POKEQ` リポジトリを作成
2. このフォルダの中身をリポジトリ直下にアップロード
3. `Settings` → `Pages`
4. `Deploy from a branch` を選択
5. `main` / `(root)` を指定して保存

通常は `https://ユーザー名.github.io/POKEQ/` で公開されます。
