# ポケモンすうどく

GitHub Pagesで動かせる、HTML/CSS/JavaScriptだけの数独ゲームです。

## 数字とポケモンの対応

1. ピカチュウ
2. イーブイ
3. ポッチャマ
4. ヒトカゲ
5. ゲンガー
6. ホゲータ
7. ニャオハ
8. クワッス
9. ミュウツー

## 画像の入れ方

`images` フォルダに次の名前でPNG画像を置いてください。

- `1_pikachu.png`
- `2_eevee.png`
- `3_piplup.png`
- `4_charmander.png`
- `5_gengar.png`
- `6_fuecoco.png`
- `7_sprigatito.png`
- `8_quaxly.png`
- `9_mewtwo.png`

画像がない場合でも、名前＋数字の代替表示でゲームは動きます。

## GitHub Pages

1. リポジトリを作成
2. このフォルダ内のファイルをアップロード
3. Settings → Pages
4. Branch を `main` / `(root)` に設定
5. 表示されたURLを開く

## 現在の機能

- 9×9数独
- 3つの問題からランダム出題
- ポケモンをタップして入力
- 最初から入っているマスは編集不可
- 行・列・3×3ブロックの重複表示
- チェック機能
- やりなおし
- 新しい問題
- 数字表示ON/OFF
- タイマー
- クリア時に9匹を個別表示する全員集合画面
- スマホ・タブレット対応
