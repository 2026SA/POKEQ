# POKEQ（ポケキュー！） v6

ポケモン9匹を 1〜9 に対応させた、GitHub Pagesで動く数独Webアプリです。
HTML / CSS / JavaScriptだけで動き、サーバーは不要です。

## v6 の主な変更

- 「新しい問題」を押すたびに数独をランダム生成
- 生成後に解の数を確認し、**解が1つだけの問題**を出題
- 難易度に「スーパーかんたん」を追加
  - スーパーかんたん：おおむね68〜72マス（空欄9〜13マス）
    - 各たて・よこ・3×3の空欄を増やしすぎない
    - 候補が1つだけのマスを順番に見つければ最後まで解ける問題だけを生成
    - 保育園児・数独が初めての子向け
  - かんたん：おおむね42〜46マス
  - ふつう：おおむね34〜38マス
  - むずかしい：おおむね28〜32マス
- 問題として固定されたマスを黄色に変更
- 自分で入力したマスを水色に変更
- 候補メモモードを追加
  - 1つのマスに複数候補を保存可能
  - 候補はポケモン画像ではなく1〜9の数字だけで表示
- 自分で確定したマスのロック／ロック解除を追加
- 「あそびかた」に候補メモ・ロック・マス色の説明を追加
- 「ミスをおしえる」は従来どおり初期OFF

## ❌（除外マーク）について

単独の❌は「9匹のうち、どのポケモンが入らないのか」が分かりにくいため、v4では採用していません。
代わりに、候補メモで「入りそうな数字だけを残す」方式にしています。

## GitHub Pages

1. `POKEQ` リポジトリを作成
2. このフォルダの中身をリポジトリ直下にアップロード
3. Settings → Pages
4. Branch を `main` / `(root)` に設定
5. 表示されたURLへアクセス

## ファイル

- `index.html` ゲーム本体
- `style.css` ゲーム画面のデザイン
- `script.js` ランダム生成・数独判定・候補メモ・ロック等
- `howto.html` 低学年向け「あそびかた」
- `howto.css` 説明ページ用
- `images/` 9匹の画像

### v6 追加機能
- 操作説明・マスの凡例を盤面の上へ移動
- スマホでは「盤面 → ポケモン選択」がすぐ続く配置に変更
- 一時中断ボタン
  - 全画面の休けい画面を表示
  - 中断中はタイマーも停止
  - 「つづきから」で同じ盤面へ復帰
- レベル別マイランキング
  - スーパーかんたん / かんたん / ふつう / むずかしい の各ベスト5
  - クリア時に自動保存
  - ブラウザの localStorage に保存されるため、同じ端末・同じブラウザで保持
  - ランキング画面からリセット可能
